# `.altitude/` — design-system metadata and contract docs

Machine-readable state and the long-form docs that state contracts too detailed
for `CLAUDE.md` / `AGENTS.md`. CI, generators and validators read from here.

Two kinds of thing live in this directory, and they are governed differently:
the **JSON/state files** below are read by scripts, so drift fails a build; the
**Markdown docs** are read by humans and agents, so drift is silent — correct
them in the same PR as the code they describe.

## State — read by scripts

| Path | Purpose | Read by |
|---|---|---|
| `targets.json` | Pinned target versions and end-state decisions | Nothing — a human/agent contract (see its own `$comment`) |
| `migration.json` | Per-component migration state (`legacy`/`dual`/`scoped-complete`) | `scripts/check-migration-gate.js` (G2), `libs/altitude-mcp/src/lib/migration.mjs` |
| `migration.schema.json` | JSON Schema for `migration.json` | CI job `schema-validate-migration` |
| `ds-projects.json` | Design-system project registry — one entry per Figma-backed DS (`altitude`, `southleft`) | `libs/altitude-mcp/src/lib/ds-project.mjs`, `scripts/figma-parity/*`, `scripts/check-ds-projects.mjs` |
| `ds-projects.schema.json` | JSON Schema for `ds-projects.json` | `scripts/check-ds-projects.mjs` |
| `bundle-budget.json` | Per-entry bundle-size ceilings | `scripts/check-bundle-budget.js` (T6.3) |
| `audit-allowlist.json` | Accepted `pnpm audit` risks, each with a reason + expiry | `scripts/check-audit.mjs` |
| `css-specificity-allowlist.json` | Sanctioned specificity escapes from the cascade-layer rule | `scripts/check-css-layers.js` (T4.1/T6.1) |
| `baselines/` | Legacy-stack baselines: `tokens/` snapshot, `bundle/` sizes, `screenshots/` VRT (G8) | `scripts/check-baselines-gate.js`, `scripts/capture-*-baseline.js`, Playwright VRT |
| `golden-snapshots/` | `<component>.scss.expected` fixtures for the scoped-theming codemod | `scripts/codemod-scoped.js` |
| `figma-sync/` | Per-project Figma parity manifests + ops. Only `parity-manifest.json` (one per project) is tracked — see `/.gitignore` | `libs/altitude-mcp/src/lib/parity.mjs`, `scripts/figma-parity/*` |
| `ai-readiness/` | `cem-digest.json` + `tokens-digest.json` — the ground truth an agent verifies tag/attribute/slot/event/token claims against. Tracked; `runs/` (probe output) is not | `scripts/ai-readiness/run-probe.mjs`, `run-judge.mjs`; regenerated by `pnpm --filter @southleft/al-web-components build` |
| `visual-compare/` | Brand-distinctiveness harness + its committed proof PNGs. Mostly gitignored — see `/.gitignore` | `scripts/check-brand-distinctiveness.js`, `scripts/check-scoped-theming.mjs` |
| `a11y/` | `report.json` (Storybook axe, per component), `report-docs.json` (docs-site axe, for components with no Storybook), `manual-tests.json` (hand-recorded screen-reader/manual passes — a record store, not a component list) | `scripts/build-a11y-report.mjs`, `scripts/build-a11y-docs-report.mjs`; rendered by `apps/docs/src/lib/a11y.mjs` |

## Rules

- Do not hand-edit `migration.json` outside a migration PR — it is the spine of
  the G2 CI gate.
- Do not hand-edit `ai-readiness/*.json`; regenerate them with
  `pnpm --filter @southleft/al-web-components build` (the `cem-and-contracts` CI job
  regenerates and `git diff --exit-code`s them).
- Adding a file here means adding a row above. Re-check with `ls -1 .altitude/`.
