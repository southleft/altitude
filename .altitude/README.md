# `.altitude/` — design-system metadata and contract docs

Machine-readable state and the long-form docs that state contracts too detailed
for `CLAUDE.md` / `AGENTS.md`. CI, generators and validators read from here.

Two kinds of thing live in this directory, and they are governed differently:
the **JSON/state files** below are read by scripts, so drift fails a build; the
**Markdown docs** are read by humans and agents, so drift is silent — correct
them in the same PR as the code they describe.

## Rules

- Do not hand-edit `migration.json` outside a migration PR — it is the spine of
  the G2 CI gate.
- Do not hand-edit `ai-readiness/*.json`; regenerate them with
  `pnpm --filter @southleft/al-web-components build` (the `cem-and-contracts` CI job
  regenerates and `git diff --exit-code`s them).
- Adding a file here means adding a row above. Re-check with `ls -1 .altitude/`.
