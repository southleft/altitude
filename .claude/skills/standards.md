# Coding Standards

The coding standards for this project are located in `.mm/standards/`.

When you need to reference coding standards:

1. Read the appropriate standard file from `.mm/standards/`
2. Apply the standards to your code
3. Never deviate from established standards without explicit user approval

## Available Standards

To see available standards, read the files in `.mm/standards/`.

## Usage

Standards are automatically applied when you write code. You should:
- Follow naming conventions
- Adhere to code organization patterns
- Respect architectural decisions
- Maintain consistency with existing code
