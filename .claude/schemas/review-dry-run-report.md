# Review Dry-Run Report Format

Version: 1.0

## Purpose

When `/mm:review --dry-run` is invoked, the review pipeline runs the full analysis and triage but writes a report instead of applying fixes. This document defines the report format.

## Report Location

- **With spec context:** `.mm/specs/{current-spec}/review/dry-run-report.md`
- **Without spec context:** Output to stdout

## Report Template

````markdown
# Code Review — Dry Run Report

**Date:** {ISO date}
**Spec:** {spec-name or "N/A"}
**Agents:** {comma-separated list of agents that ran}
**Mode:** Dry Run (no changes applied)

## Summary

| Tier             | Count       | Action                            |
| ---------------- | ----------- | --------------------------------- |
| High (auto-fix)  | {count}     | Would be applied automatically    |
| Medium (suggest) | {count}     | Would be presented as suggestions |
| Low (advisory)   | {count}     | Informational only                |
| **Total**        | **{total}** |                                   |

## High Confidence — Would Auto-Fix

{#if count > 0}
{#each finding}

### {finding.id}: {finding.title}

- **Agent:** {finding.agent}
- **File:** `{finding.file}`:{finding.line}
- **Fix:** {finding.fix_description}

```diff
{finding.diff_suggestion}
```
````

{/each}
{:else}
No high-confidence fixable issues found.
{/if}

## Medium Confidence — Suggestions

{#if count > 0}
{#each finding}

### {finding.id}: {finding.title}

- **Agent:** {finding.agent}
- **File:** `{finding.file}`:{finding.line}
- **Description:** {finding.description}
- **Suggested fix:** {finding.fix_description}

{#if finding.diff_suggestion}

```diff
{finding.diff_suggestion}
```

{/if}

{/each}
{:else}
No medium-confidence suggestions.
{/if}

## Low Confidence — Advisory

{#if count > 0}
| # | Agent | File | Issue |
|---|-------|------|-------|
{#each finding}
| {finding.id} | {finding.agent} | `{finding.file}`:{finding.line} | {finding.title} |
{/each}
{:else}
No low-confidence advisories.
{/if}

---

_Generated by Monday Morning Code Review_
_To apply high-confidence fixes, run: `/mm:review --auto-fix`_

```

## Usage Notes

- The dry-run report is a preview of what `--auto-fix` would do
- It helps developers audit the auto-fixer before trusting it
- The report can be committed to the spec review folder for team reference
- Running `--dry-run` is safe — it never modifies files or creates commits
```
