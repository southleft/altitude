Altitude ships tokens, components, and an MCP server that let humans and AI agents build from the same source of truth. Every color pairing is solved and checked against WCAG AA before it ever reaches the screen — by construction, not by review.

The contract behind every screen

Numbers computed from this repository at build time — not marketing copy.
Built for agents

An MCP server exposes every token, component, and usage pattern as structured data — so an AI agent and a developer pull component APIs from the exact same source of truth, not a stale doc someone forgot to update.
AI theming, provably accessible

A deterministic OKLCH engine derives a full theme from a prompt and enforces WCAG AA contrast on every pairing before it applies — the model directs, the solver guarantees.
Scoped multi-brand theming

<al-theme> scopes brand, mode, density, and contrast per subtree — multiple brands can coexist on a single page, each rendering its own tokens.
SSR & Declarative Shadow DOM

Components render real HTML on the first response via @lit-labs/ssr and Declarative Shadow DOM — no client-side flash of unstyled content.
Versioned registry & Figma sync

Stable, versioned, or manual registration lets multiple Altitude versions coexist in one app, while tokens round-trip with the Figma source file.
