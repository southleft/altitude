# Czat AI

::: warning Niedostępne w tej dystrybucji
Wbudowany czat AI, skrót <kbd>⌘</kbd><kbd>J</kbd> oraz ustawienia **AI i agenci** i **Użycie** nie są dostępne w tej dystrybucji. Zamiast tego połącz agenta, z którego już korzystasz, np. Claude Code, Claude Desktop lub Cursor, przez [serwer MCP](/programmable/mcp-server). Przycisk **Połącz AI** u góry prawego panelu pokazuje kroki konfiguracji; zobacz [Connect AI](/programmable/mcp-server#connect-ai).
:::

Agenci połączeni przez MCP korzystają z Twojej własnej subskrypcji, więc OpenPencil nie potrzebuje kluczy API dostawców. Pracują na dokumencie otwartym w aplikacji komputerowej.

## Możliwości

Agenci korzystają z ponad 90 narzędzi do tworzenia, stylizowania, układu, komponentów, zmiennych, wyszukiwania, inspekcji, analizy, eksportu i operacji wektorowych.

## Kontrola wizualna

Po utworzeniu lub zmianie projektu agent może wywołać `export_image`, uzyskać obraz wyniku i porównać go z pierwotnym poleceniem. Pozwala to wykryć problemy z układem, brakujące elementy i nieprawidłowe kolory.

## Wskazówki

- Przed wysłaniem polecenia zaznacz odpowiednie obiekty: agent widzi zaznaczenie.
- Dokładnie podawaj kolory, rozmiary i położenie.
- Jedno polecenie może zmienić kilka obiektów.
- Wszystkie zmiany AI można cofnąć.
- Po każdym wywołaniu narzędzia układ jest przeliczany automatycznie.
