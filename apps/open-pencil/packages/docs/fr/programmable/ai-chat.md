# Chat avec l’AI

::: warning Non disponible dans cette distribution
Le chat AI intégré, le raccourci <kbd>⌘</kbd><kbd>J</kbd> et les réglages **IA et agents** et **Utilisation** ne sont pas inclus dans cette distribution. Connectez plutôt un agent que vous utilisez déjà, comme Claude Code, Claude Desktop ou Cursor, via le [serveur MCP](/programmable/mcp-server). Le bouton **Connecter l’IA** en haut du panneau de droite affiche les étapes de configuration ; voir [Connect AI](/programmable/mcp-server#connect-ai).
:::

Les agents connectés via MCP utilisent votre propre abonnement : OpenPencil n’a besoin d’aucune clé d’API de fournisseur. Ils travaillent sur le document ouvert dans l’application de bureau.

## Outils

Les outils couvrent lecture, création, modification, structure, variables, vecteurs, analyse, description, génération de code et images de stock. Chaque appel agit sur l’éditeur actif et participe à l’historique d’annulation lorsque cela s’applique.
