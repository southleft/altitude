<h2 class="wp-block-heading"><strong>Unlocking Academic Success</strong> </h2>
<p>We collaborated with <a href="https://superfriendly.com/">SuperFriendly</a> to create front-end components and a comprehensive design system for <a href="https://www.enotes.com/">eNotes</a>. The challenge was twofold: to deliver top-notch user experience and to enable seamless integration with eNotes’ in-house content management system (CMS).</p>

<h2 class="wp-block-heading"><strong>Engagement 101: The Puzzle and the Pieces</strong> </h2>
<p>The core challenge was elevating user engagement on eNotes’ educational, subscription-based platform. We were tasked with developing modular, intuitive components that could be effortlessly incorporated into eNotes’ pre-existing CMS.</p>
