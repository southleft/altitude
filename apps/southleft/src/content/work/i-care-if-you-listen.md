<h2 class="wp-block-heading">A migration that went beyond the surface</h2>
<p>The original site was running an unsupported theme and incompatible with the latest version of PHP. The team also wanted to leave WP Engine for a more secure and stable hosting environment. We migrated I Care If You Listen to a shared WordPress multisite architecture alongside <a class="" href="https://innova.mu/" target="_blank" rel="noopener" data-start="1406" data-end="1434">Innova</a> and <a class="" href="https://composersforum.org/" target="_blank" rel="noopener" data-start="1439" data-end="1488">American Composers Forum</a>, hosted on Pantheon.</p>

<h2 class="wp-block-heading">Powered by Northright</h2>
<p>We rebuilt the front end using <a class="" href="/northright/" target="_new" rel="noopener" data-start="1574" data-end="1610">Northright</a>, Southleft’s in-house WordPress theme designed for performance, accessibility, and modularity. This gave the publication a fresh editorial experience and modern visual consistency across all templates.</p>
</div>
</div>
</div>
</div>
</div>

<h2 class="wp-block-heading">Solving for Scale</h2>
<p>With over 300 legacy users and thousands of archived posts, the migration required more than a simple export. We developed custom scripts and SQL commands to ensure that users, posts, and permissions remained intact after being moved into the shared database structure of WordPress multisite. We also migrated WordPress users to a dedicated custom post type to make managing editors more intuitive and scalable.</p>

<h2 class="wp-block-heading">Results</h2>
<p>The site launched on time and has seen significant improvements in performance and maintainability. Editors now have a cleaner, faster interface for publishing, and the new multisite setup provides a more secure and future-ready foundation.</p>
