# Changelog

All notable changes to the Altitude design system (`al-web-components` and
`al-react`) are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Entries are generated from individual changeset files in `.changeset/` at release
time (see `NEXT-GEN-UPGRADE-PLAN.md` task T6.4). The legacy hand-written template
below is preserved for one-off pre-v2 patches if needed.
